Proyectos y casos de estudio · noviembre 26, 2023

Caracterización de géneros musicales a partir de señales de audio

Objetivo. Investigar qué características de una señal de audio permiten describir y comparar distintos géneros musicales.

Enfoque. Con Python y Librosa extraje características de 100 canciones de jazz, ópera, rap, reggae y rock. Generé un dataset analítico y apliqué PCA y clustering para explorar agrupaciones y diferencias entre géneros.

Valor aportado. El proyecto construye un flujo completo desde señales no estructuradas hasta un conjunto de variables apto para machine learning, combinando fundamentos de procesamiento de señal con análisis exploratorio. Proyecto académico del Máster en Ciencia de Datos de la Universitat de València.
